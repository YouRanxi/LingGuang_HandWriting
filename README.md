## 下载

到 [**Releases**](../../releases/latest) 下载 `LingGuangInk-v1.16.1.zip`，解压后双击 `Start.bat` 即可。

## 三种模式

上手前唯一需要理解的地方 —— 它决定**手指能不能操作下层应用**。

| 模式 | 触控笔 | 手指 / 鼠标 | 怎么进 |
|---|---|---|---|
| **涂鸦模式**（默认） | ✅ 可以书写 | ❌ 只能操作画板 | 启动默认 |
| **穿透模式** | ⚠️ 一起穿透 | ✅ 可以操作下层网页 / 软件 | 点工具栏「穿透」 |
| **自动手笔分离** | ✅ 可以书写 | ✅ 可以操作下层 | 点工具栏「自动手笔分离」 |

**日常推荐用「自动手笔分离」**：开启后笔靠近屏幕就能写，笔一离开手指就能滑网页，全程不用按键。

> 想要「笔能写 + 手指也能操作下层」，就用自动手笔分离。
> 穿透模式会让整块画板一起让路，笔也会跟着穿透出去。

## 界面

### 主栏按钮

| 按钮 | 作用 |
|---|---|
| `>` / `<` | 收起为悬浮球。按钮会自动跑到菜单另一端，始终贴着你停靠的那一侧 |
| 拖动把手 | 按住可把工具栏拖到屏幕任意位置 |
| 钢笔 · 荧光笔 · 橡皮 | 切换绘图工具 |
| 颜色 | 打开调色板 |
| 撤销 · 清屏 | 撤销上一步 / 一次清空 |
| 穿透 | 切换穿透模式 |
| 自动手笔分离 | 切换自动手笔分离 |
| `⋯` | 展开「更多」面板 |

### 更多面板

激光教鞭 · 几何图形 · 笔触粗细 · 手笔分离 · 背景底衬 · 自定义画板 · 重做 · 截图标注 · 设置 · 退出

### 收起后的悬浮球

点 `>` 收起后，工具栏变成一个 44×44 的小球，可拖到屏幕任意角落，点一下即弹回展开。

## 工具

| 工具 | 说明 |
|---|---|
| 压感钢笔 | 支持 4096 级压感，轻重力道自然 |
| 荧光笔 | 半透明，高亮文字但不遮住下层内容 |
| 激光教鞭 | 光轨约 1.2 秒自动淡出，适合讲演指点 |
| 几何图形 | 直线 / 箭头 / 矩形 / 椭圆，拖动时有实时预览 |
| 橡皮擦 | 两种模式，见下 |

### 橡皮擦的两种模式

点橡皮按钮弹出选择：

- **笔迹擦除** —— 碰到哪条线，整条一起擦掉
- **像素擦除** —— 像真橡皮一样，抹掉一片

### 颜色

点颜色按钮打开调色板：

- 上方 10 个预设色块，点一下即换色
- 点下方箭头展开**色轮**，拖色相环与方块任意调色
- 色轮下方可**直接输入色码**（如 `#FF4D4F`），回车生效

### 笔触粗细

点粗细按钮打开滑块，范围 1–40 px。

面板顶部有一个**按真实粗细渲染的圆点**，拖滑块时实时变化。
钢笔、荧光笔、**像素橡皮**三者同步 —— 预览显示多大，橡皮就擦多大。

### 背景底衬

透明桌面 ⇋ 纯白白板 ⇋ 护眼黑板，一键切换。

## 自定义画板

在「更多」面板里点画板按钮，会弹出一块**悬浮小黑板**：

| 操作 | 效果 |
|---|---|
| 拖标题栏 | 移动位置 |
| 拖右下角三角 | 自由缩放 |
| 图钉 | 切换置顶。置顶时浮在所有窗口之上 |
| 粉笔 / 黑板擦 | 切换书写与擦除 |
| 擦净整块 | 一次清空（可撤销） |

## Surface Pen

- **4096 级压感** —— 直接使用 Windows Ink 硬件压感
- **笔尾橡皮擦** —— 翻转笔尾接触屏幕即擦除，转回笔尖自动恢复
- **笔身侧键** —— 按住侧键接触屏幕快速擦除，松开还原
- **双指轻触撤销** —— 任意两指同时轻点屏幕，撤销上一步

### 用笔按钮切换模式

把 Surface Pen 顶部按钮绑定到 `LingGuangInk.App.exe`，
之后**按一下笔就能在涂鸦 / 穿透模式之间切换**。

绑定位置：**设置 → 蓝牙和设备 → 笔和 Windows Ink → 手写笔快捷方式**

---

## 撤销与重做

- **一笔算一步**，写得再快也不会被合并
- **一次擦除算一步**，擦完按一次撤销即可整体还原
- 最多可回退 100 步
- 清屏也可一次撤销

## 设置

点工具栏「设置」打开面板，改动**即时生效**。

| 选项 | 说明 |
|---|---|
| 开启严格手笔分离（防手掌误触） | 手掌贴屏也不会画上东西，只认触控笔 |
| 启用双指轻触撤销手势 | 双指轻点屏幕撤销上一步 |
| 启用 Surface Pen 侧键长按快速擦除 | 按住笔身侧键擦除 |
| 允许鼠标绘画 | 没拿笔时也能用鼠标涂鸦 |

设置会自动保存到 `%LOCALAPPDATA%\LingGuangInk\settings.ini`，下次启动仍然生效。

## 常见问题

**手指点不动下层网页 / 按钮？**

当前是**涂鸦模式**。点工具栏「穿透」或「自动手笔分离」。

**开了穿透之后笔也写不了了？**

穿透模式会让整块画板一起让路。要「笔能写 + 手指能操作下层」，请用**自动手笔分离**。

**工具栏不见了？**

可能被收起了 —— 找屏幕边缘的 44×44 悬浮球，点一下弹回。
若处于穿透或自动模式，点**右下角的悬浮球**，从菜单里切回来。

**设置改了，重启就没了？**

不会。设置保存在 `%LOCALAPPDATA%\LingGuangInk\settings.ini`，可手工编辑。

**遇到异常想反馈？**

程序目录下会生成 `nchittest.log`，把它一起发出来即可。

## 从源码构建

克隆仓库后双击 `Build.bat` —— 它调用 Windows 自带的 `csc.exe`，无需安装任何开发环境。

| 脚本 | 用途 |
|---|---|
| `Build.bat` | 编译并部署到 `LingGuangInk.App.exe` |
| `Start.bat` | 启动程序 |
| `Reset.bat` | 需管理员权限。清理历史进程后重启 |
